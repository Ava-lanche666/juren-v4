聚仁网页版源代码（GitHub Pages 版）

这是无需构建的静态网站。HTML、CSS、JavaScript 源码和本地 OCR 所需资源都在 dist/。
本地预览：进入 dist 目录，运行 python3 -m http.server 8000，然后访问 http://localhost:8000。
数据加密后保存在浏览器本地；本压缩包不包含你的个人数据。

发布地址：https://ava-lanche666.github.io/juren-v4/
将网站文件放在仓库根目录（index.html、assets/、js/ 等），推送至 main 后由 GitHub Pages 发布。
此网站的数据属于 github.io 的浏览器存储空间，和 chatgpt.site 地址的数据不自动互通；更换网址前请在旧站导出加密备份，并在新站导入。
